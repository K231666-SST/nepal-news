## 1. Introduction

Nepal News Australia is a bilingual news platform serving the Nepali-Australian diaspora. This manual covers all four user roles: Reader, Contributor, Editor, and Administrator.

---

## 2. Getting Started

### 2.1 Accessing the Site
Open any modern browser and go to: **https://nepal-news.onrender.com**

> Note: The free hosting plan may take 30–50 seconds to wake up after inactivity. Wait and refresh if the page appears blank.

### 2.2 Creating an Account
1. Click **Sign In** in the top right corner
2. Click **Register** below the login form
3. Enter your full name, email, and password (minimum 8 characters)
4. Click **Register** — you are automatically logged in as a Reader

## 3. Reader Guide

Readers can browse all published news without an account.

### 3.1 Homepage Sections

| Section | Description |
|---------|-------------|
| Breaking News Ticker | Latest breaking stories scrolling at top |
| Hero Section | Top 3 featured articles with images |
| Latest News Grid | All recent articles with category filter tabs |
| Community Events | Upcoming events for Nepali Australians |
| Trending Now (sidebar) | Top 5 most-viewed articles |
| Live Widgets (sidebar) | Weather, gold price, currency, horoscope |
| Newsletter (sidebar) | Email subscription form |

### 3.2 Reading an Article
1. Click any article headline or image
2. Full article loads with content, author, date, and view count
3. Share buttons at the bottom: Facebook, Twitter, Copy Link

### 3.3 Browsing by Category
Use the navigation bar to browse: **Nepal, Australia, Community, Business, Sports, Entertainment, Opinion, Culture**

### 3.4 Live Sidebar Widgets

| Widget | What It Shows |
|--------|--------------|
| Weather | Temperature for Sydney, Melbourne, Brisbane, Kathmandu |
| Gold & Silver | Live AUD prices per gram |
| Currency | Live NPR to AUD exchange rate |
| Rashifal | Daily horoscope — click any zodiac sign to view |
| Nepali Date | Today in Bikram Sambat with Hamro Patro link |

### 3.5 Guru AI Assistant
1. Click the red circular button (🧿) in the bottom-left corner
2. Type any question and press Enter
3. Quick prompts available: **Summarise, Translate, Nepal News**

Example questions:
- "Summarise this article for me"
- "Translate hello to Nepali"
- "What is Dashain?"

### 3.6 Newsletter Subscription
1. Find the Newsletter widget in the sidebar
2. Enter your email and click **Subscribe**
3. Confirmation message appears

### 3.7 Language Toggle
1. Find the **English / Nepali** buttons in the top bar
2. Click **Nepali** — interface switches to Devanagari script
3. Click **English** to switch back
4. Preference is saved in your browser

## 4. Contributor Guide

Contributors can write articles and submit them for editorial review.

### 4.1 Writing a New Article
1. Log in as Contributor
2. Click **+ Write** in the navigation bar
3. Fill in all required fields:

| Field | Required |
|-------|----------|
| Title | Yes |
| Category | Yes |
| Summary | Yes |
| Content | Yes |
| Featured Image URL | Optional |
| Tags | Optional |

4. Click **Save as Draft** or **Submit for Review**

### 4.2 Article Status Workflow

| Status | Meaning |
|--------|---------|
| Draft | Saved, not yet submitted |
| Pending | Submitted, awaiting editor review |
| Published | Live on the website |

---

## 5. Editor Guide

Editors can publish, edit, and delete all articles, and approve events.

### 5.1 Publishing Articles
1. Go to **Dashboard**
2. Click **Articles** tab — Pending articles are listed
3. Click **Edit** to review, then click **Publish**

### 5.2 Approving Events
1. Go to **Dashboard**
2. Click **Events** tab
3. Click **Approve** next to pending events

---

## 6. Administrator Guide

Administrators have full access including user management and advertisement control.

### 6.1 Managing Users
1. Go to **Dashboard** → **Users** tab
2. Change any user's role using the dropdown
3. Changes take effect immediately

### 6.2 Advertisement Manager
1. Click **Ads** in the navigation bar
2. Click **Create New Ad** to add an advertisement

| Ad Position | Description |
|-------------|-------------|
| Sidebar Top | Top of right sidebar on all pages |
| Sidebar Middle | Mid-sidebar |
| Sidebar Bottom | Bottom of sidebar |
| Homepage Banner | Full-width banner on homepage |
| Article Inline | Embedded within article content |
| Header Banner | Below the navigation bar |

3. Set type: **Image**, **Text**, or **HTML Code**
4. Toggle **Active** to make it live

---

## 7. Community Events

### 7.1 Submitting an Event
1. Go to **Events** page
2. Scroll to the Submit form
3. Fill in: title, description, date, venue, city, organiser, category
4. Click **Submit Event**
5. Event appears as pending until approved by an editor

## 8. Troubleshooting

| Problem | Solution |
|---------|----------|
| Site loads slowly | Wait 30–60 seconds — free hosting cold start |
| Cannot log in | Check email/password; use demo credentials to test |
| Guru says 'short break' | API temporarily busy — try again in a moment |
| Cannot publish article | Only Editors and Admins can publish |
| Language switch not working | Ensure JavaScript is enabled in browser |
| Page shows 500 error | Refresh; if persists contact admin |

# 5\. Known Issues & Limitations

*   Render.com cloud deployment encounters Docker build issues — application runs correctly locally
*   Mailgun email requires authorized recipient on sandbox plan — full email delivery requires production domain
*   Nepali date calculation uses approximation — exact BS conversion requires lookup tables for historical accuracy

# 6\. User Acceptance Testing

UAT was conducted with 3 community members from the Nepalese-Australian diaspora. Feedback was positive — users found the site professional, easy to navigate, and culturally relevant. Key UAT findings:

*   Homepage hero section effectively highlights breaking news
*   Category navigation was intuitive for all test users
*   Mobile experience on iPhone was smooth and responsive
*   Nepali language switcher was appreciated by Nepali-speaking testers

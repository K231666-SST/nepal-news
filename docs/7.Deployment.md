# 1\. Deployment Overview

The Nepal News Australia application is developed locally using XAMPP (MySQL) and PHP Artisan serve. The application has been configured for cloud deployment using Docker and GitHub for version control. The production deployment target is Render.com using Docker containers.

# 2\. Local Development Setup

## 2.1 Requirements

*   PHP 8.5.5 or higher
*   Composer 2.x
*   MySQL 8.0 (XAMPP recommended for macOS/Windows)
*   Git

## 2.2 Installation Steps

1.  Clone the repository: git clone https://github.com/K231666-SST/nepal-news.git
2.  Install PHP dependencies: composer install
3.  Copy environment file: cp .env.example .env
4.  Generate application key: php artisan key:generate
5.  Configure .env with MySQL credentials (DB\_PORT=3307)
6.  Run migrations and seeders: php artisan migrate --seed
7.  Create storage link: php artisan storage:link
8.  Start development server: php artisan serve --port=8080
9.  Visit: http://localhost:8080

# 6\. Cloud Deployment

Cloud deployment was attempted on Render.com using Docker containers. The Docker configuration is included in the repository (Dockerfile, docker/apache.conf). Due to free-tier limitations with database seeding in Docker build environments, the production deployment serves the application from the Docker image with SQLite for demonstration purposes. The full application with all data runs on the local environment.

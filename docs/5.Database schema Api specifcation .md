# 1\. Database Schema

## 1.1 users

| Column | id (PK), name, email (unique), email_verified_at, password, role, remember_token, timestamps |
| --- | --- |
| Role Values | admin | editor | contributor | reader |
| Indexes | PRIMARY KEY (id), UNIQUE KEY (email) |

## 1.2 articles

| Column | id (PK), user_id (FK), title, slug (unique), summary, content, category, status, is_featured, is_breaking, image_url, views, timestamps |
| --- | --- |
| Category | nepal | australia | community | business | sports | entertainment | opinion | culture |
| Status | draft | pending | published | archived |
| Foreign Keys | user_id REFERENCES users(id) ON DELETE CASCADE |

## 1.3 tags & article\_tag

| tags columns | id (PK), name, slug (unique) |
| --- | --- |
| article_tag columns | article_id (FK), tag_id (FK) — composite primary key |

## 1.4 events

| Columns | id, user_id (FK), title, description, date, time, location, city, price, is_free, is_approved, timestamps |
| --- | --- |
| Foreign Keys | user_id REFERENCES users(id) |

## 1.5 advertisements

| Columns | id, title, position, type, image_url, link_url, ad_code, alt_text, is_active, starts_at, ends_at, impressions, clicks, created_by (FK), timestamps |
| --- | --- |
| Position | sidebar_top | sidebar_middle | sidebar_bottom | header_banner | article_inline | homepage_banner |
| Type | image | code | text |

# 2\. API Specification

## 2.1 Internal API Endpoints

| Method | Endpoint | Auth | Description |
| --- | --- | --- | --- |
| GET | /api/weather | None | Live weather for 4 cities |
| GET | /api/gold | None | Live AUD gold & silver prices |
| GET | /api/currency | None | NPR to AUD exchange rate |
| GET | /api/horoscope | None | Daily horoscope by sign |
| GET | /api/nepali-date | None | Today in Bikram Sambat |
| GET | /api/health | None | Application health check |
| POST | /newsletter/subscribe | None | Subscribe email to newsletter |
| POST | /ads/{ad}/click | None | Track advertisement click |
| GET | /dashboard | Auth | Admin dashboard stats |
| GET | /admin/ads | Admin | List all advertisements |
| POST | /admin/ads | Admin | Create new advertisement |
| PUT | /admin/ads/{ad} | Admin | Update advertisement |
| DELETE | /admin/ads/{ad} | Admin | Delete advertisement |

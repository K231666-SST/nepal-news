# 1\. Architecture Overview

Nepal News Australia follows the Model-View-Controller (MVC) architectural pattern as implemented by the Laravel framework. The system is a monolithic web application with clear separation of concerns between data, business logic, and presentation layers.

# 2\. Technology Stack

| Framework | Laravel 13.7.0 (PHP 8.5.5) |
| --- | --- |
| Frontend | Laravel Blade Templates + Custom CSS |
| Database | MySQL 8.0 via XAMPP (port 3307) |
| Auth | Laravel Breeze (session-based) |
| APIs | OpenWeatherMap, MetalPriceAPI, ExchangeRate-API, Horoscope App API |
| Email | Mailgun SMTP |
| Version Ctrl | Git + GitHub |
| Local Server | PHP Artisan serve (port 8080) |

# 3\. MVC Architecture

## 3.1 Models (app/Models/)

Models represent database tables and handle data logic using Laravel Eloquent ORM.

| Model | Table | Key Relationships |
| --- | --- | --- |
| User | users | hasMany Articles, Comments |
| Article | articles | belongsTo User, hasMany Tags |
| Tag | tags | belongsToMany Articles |
| Event | events | belongsTo User |
| Comment | comments | belongsTo User, Article |
| Advertisement | advertisements | belongsTo User |

## 3.2 Controllers (app/Http/Controllers/)

*   HomeController — Fetches featured articles, breaking news, trending articles, events for homepage
*   ArticleController — CRUD operations for articles, publish/unpublish, search
*   DashboardController — Admin statistics, user management, pending approvals
*   EventController — Community event creation, listing, approval workflow
*   ApiController — Proxy endpoints for Weather, Gold, Currency, Horoscope APIs
*   AdvertisementController — Full ad management with impression/click tracking

## 3.3 Views (resources/views/)

*   layouts/app.blade.php — Master layout with navigation, footer, sidebar
*   layouts/guest.blade.php — Authentication layout with animated logo
*   pages/ — Homepage, category, article, events, search pages
*   admin/ — Dashboard, article form, advertisement manager
*   components/ — Sidebar widgets, ad slots, pagination

# 4\. Database Architecture

The database contains 8 tables with properly defined relationships and foreign key constraints.

| Table | Key Columns | Purpose |
| --- | --- | --- |
| users | id, name, email, password, role | User accounts and roles |
| articles | id, title, slug, content, category, status, user_id | News articles |
| tags | id, name, slug | Article tags |
| article_tag | article_id, tag_id | Many-to-many pivot |
| events | id, title, date, location, city, user_id | Community events |
| comments | id, body, article_id, user_id | Article comments |
| advertisements | id, title, position, type, image_url, is_active | Ad management |
| subscribers | id, email, is_active | Newsletter subscribers |

# 5\. Authentication & Security

*   Session-based authentication via Laravel Breeze
*   CSRF protection on all forms using @csrf Blade directive
*   Passwords hashed using bcrypt (Laravel default)
*   Route middleware: auth (requires login), admin-only checks in controllers
*   Role-based access: isAdmin(), isEditor(), isContributor() methods on User model

# 6\. API Integration Architecture

External APIs are proxied through Laravel's ApiController to protect API keys and enable caching. Frontend JavaScript calls internal /api/\* endpoints rather than external APIs directly.

*   /api/weather — Proxies OpenWeatherMap API for 4 cities
*   /api/gold — Proxies MetalPriceAPI for AUD gold/silver prices
*   /api/currency — Proxies ExchangeRate-API for NPR/AUD rates
*   /api/horoscope — Proxies Horoscope App API for daily readings
*   /api/nepali-date — Calculates Bikram Sambat date from current AD date

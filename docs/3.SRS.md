# 1\. Introduction

## 1.1 Purpose

This Software Requirements Specification (SRS) defines the functional and non-functional requirements for the Nepal News Australia web platform.

## 1.2 Scope

Nepal News Australia is a full-stack Laravel web application providing news content management, user authentication, role-based access control, event management, and live API integrations for the Nepalese-Australian community.

# 2\. User Personas

**Admin — Nabin (Platform Manager)**

Goal: Manage all content, users, and advertisements. Needs full access to CMS, user roles, and site settings.

**Editor — Priya (Journalist)**

Goal: Review, edit and publish articles submitted by contributors. Needs article management access.

**Contributor — Bikash (Community Writer)**

Goal: Write and submit articles for review. Needs article creation access.

**Reader — Sita (Community Member)**

Goal: Read news, find events, subscribe to newsletter. Needs browsing and search access.

# 3\. Functional Requirements

## 3.1 Content Management System

*   FR-01: Admin and Editor can create, edit, publish, and delete articles
*   FR-02: Contributors can create and submit articles for review
*   FR-03: Articles must belong to a category (Nepal, Australia, Community, Business, Sports, Entertainment, Opinion, Culture)
*   FR-04: Articles support tags for fine-grained categorisation
*   FR-05: Articles have status: Draft, Pending, Published, Archived
*   FR-06: Articles display author, publication date, category, and view count

## 3.2 User Management

*   FR-07: Users can register with email and password
*   FR-08: Users can log in and log out securely
*   FR-09: Admin can assign roles: Admin, Editor, Contributor, Reader
*   FR-10: Role-based access control restricts features by role

## 3.3 Content Features

*   FR-11: Search by keyword across article titles and content
*   FR-12: Filter articles by category
*   FR-13: Social media share buttons on article pages (Facebook, Twitter/X)
*   FR-14: Newsletter subscription saves email to database
*   FR-15: Community events with date, location, and description

## 3.4 Live API Integrations

*   FR-16: Live weather widget for Sydney, Melbourne, Kathmandu, Brisbane
*   FR-17: Live gold and silver price widget in AUD
*   FR-18: NPR to AUD currency converter
*   FR-19: Daily Rashifal (Horoscope) for all 12 zodiac signs
*   FR-20: Nepali calendar (Bikram Sambat) date widget

## 3.5 Advertisement Management

*   FR-21: Admin can create, edit, activate/deactivate, and delete advertisements
*   FR-22: Ads support image upload, URL, HTML code, and text formats
*   FR-23: Ads can be assigned to positions: Sidebar, Header, Article Inline, Homepage
*   FR-24: System tracks impression and click counts per ad

# 4\. Non-Functional Requirements

*   NFR-01: Responsive design for desktop, tablet, and mobile
*   NFR-02: Page load time under 3 seconds on standard connection
*   NFR-03: Support for English and Nepali language
*   NFR-04: Secure authentication using CSRF protection and hashed passwords
*   NFR-05: MySQL database with migrations for schema version control
*   NFR-06: Source code maintained in GitHub with version control
